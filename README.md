# 🐦 JusPeak

**JusPeak** — это backend-часть социальной платформы микроблогов (аналог Twitter). Проект позволяет пользователям публиковать посты и вести дискуссии в виде древовидных комментариев.

🚧 **Статус проекта:** Находится в стадии активной разработки. Сейчас ведется проектирование архитектуры и API-контрактов.

🛠 Технологический стек

- **Язык/Фреймворк:** Java 17+ / Spring Boot
- **Проектирование API:** OpenAPI 3.0 (Swagger)
- **Базы данных:** MongoDB + jOOQ
- **Сборка:** Maven

## 🏗 Архитектурные подходы

1. **API-First Approach (OpenAPI)**
    Файл спецификации `api.yaml` описывает все REST-эндпоинты, форматы запросов и ответов. DTO и интерфейсы контроллеров генерируются автоматически на этапе сборки Maven.
3. **Гибридная работа с данными (MongoDB + jOOQ)**
   - **MongoDB:** Используется для хранения неструктурированного контента (тексты постов, медиа, древовидные структуры комментариев).
   - **jOOQ:** Применяется для построения запросов в реляционной модели данных (управление пользователями, подписками и сложными связями).

## 📂 Структура проекта (API)

*Основной контракт API находится в папке:* `/src/main/resources/openapi/api.yaml`

**Планируемые основные эндпоинты:**
- `POST /api/v1/posts` — создание нового поста
- `GET /api/v1/posts/{id}` — получение поста с веткой комментариев
- `POST /api/v1/posts/{id}/comments` — добавление комментария
